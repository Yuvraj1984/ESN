# ESN Supplements Website

Eine Informations-Website über ESN (Elite Sports Nutrition) – Sportnahrung und
Nahrungsergänzungsmittel.

## Dateien

| Datei          | Beschreibung                                   |
| -------------- | ---------------------------------------------- |
| `esn.html`     | Pur-HTLM5-Version, nur semantisches HTML (ohne CSS/JS) |
| `esn-modern.html` | Modernes Design mit Farben, Bildern und Video-Links |

## Aufbau der Seite

- Header mit Seitentitel und Sprungmarken-Navigation
- Produktbereiche: Proteine, Performance und Health/Vitalstoffe
- Einnahmetabelle (Zeit, Dosierung, Einsatzzweck)
- FAQ-Bereich
- Kontaktformular
- Video-Bereich mit echten YouTube-Links zum ESN Designer Whey

## Öffnen

Einfach eine der `.html`-Dateien im Browser öffnen.

## Videos

Im Abschnitt „Videos" der modernen Version sind echte YouTube-Filme zum
ESN Designer Whey verlinkt.
